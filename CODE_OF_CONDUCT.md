# Code of Conduct

## Our commitment

The D3X8 project aims to be a respectful place to learn, build, review, and discuss operating-system development. Everyone participating in project spaces is expected to help keep them welcoming and constructive.

## Expected behavior

- Be respectful, patient, and considerate.
- Critique code and ideas, not people.
- Explain technical disagreements with evidence.
- Accept good-faith corrections and differing levels of experience.
- Give useful, actionable feedback.
- Respect privacy and do not publish another person's private information.
- Follow the project's security-reporting process for vulnerabilities.

## Unacceptable behavior

- Harassment, threats, intimidation, or personal attacks.
- Discriminatory or hateful language.
- Deliberate disruption, spam, or repeated bad-faith interactions.
- Publishing private information without consent.
- Abusive conduct in issues, pull requests, reviews, discussions, or other project spaces.

## Enforcement

Project maintainers may edit or remove inappropriate content, close discussions, or restrict participation when necessary. Responses should be proportionate to the behavior and its impact.

To report a conduct concern, contact the repository maintainer privately through the GitHub profile linked from the repository. Do not use public issue comments for sensitive reports. Security vulnerabilities must instead follow [SECURITY.md](SECURITY.md).

This code applies in project repositories and other spaces when someone is representing or directly participating in D3X8.
